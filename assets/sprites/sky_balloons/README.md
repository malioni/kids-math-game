# Sky Balloons sprites

**Every PNG in this folder is a programmer-art placeholder.** Replace each with final art using
the **same filename and dimensions** and the scenes pick it up unchanged.

| File | Size | Notes |
|---|---|---|
| `bg_sky.png` | 1800×1000 | Sky; the 1280×720 play area is centred, like `bg_river.png` |
| `cloud.png` | 300×140 | Scrolls past to show rising/falling; drawn semi-transparent |
| `balloon.png` | 128×150 | Drawn **white** and tinted per balloon via `self_modulate`. Round body centred at (64, 62), radius 60; knot below. The number is a Label on top |
| `basket.png` | 150×90 | Rim along the top edge; the fox sits behind it |
| `sandbag.png` | 120×120 | Weight sign; leave the face blank (the target is a Label) |
| `lift_badge.png` | 120×120 | Where the strings meet; leave the face blank (the lift total is a Label) |

The fox reuses the Forest Bridge character sheets (idle, celebrate, fall).

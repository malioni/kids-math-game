# PLAN.md — World 4: The Picnic (division as fair sharing)

> GitHub issue: not filed. Design agreed with the user in conversation (2026-10-29).

## Feature
A new Picnic world where the fox and some friends sit at plates and each fruit's basket shows only how many it holds (e.g. 12 strawberries). The child fills the fox's plate and presses Go, the basket deals the same amount to every friend, and the picnic succeeds only if everyone got the same and nothing is left over.

---

## Scope

**Included:**
- `FruitDrag` (extends `DragPiece`): one piece of fruit the child can drag or tap
- `SharingMechanic`: one basket per fruit showing its total, the fox's plate (one row per fruit), guest animals each with a plate, a Go button, the dealing animation, and the friends' reactions; emits `correct` / `incorrect` once the deal has played
- `SharingPuzzleGenerator`: picks the plate count and each fruit's share from per-level ranges using the world's RNG
- `scripts/worlds/picnic.gd` (extends `WorldBase`) + `scenes/worlds/picnic/picnic.tscn`: the fox, celebrate and sad reactions, confetti, retry prompt, `LevelHud`
- 20 level JSON files + `levels.json` in `data/levels/world_picnic/`
- Registration in `GameRegistry` (fourth world, after market)
- Placeholder art generated by a headless GDScript tool (`tools/make_picnic_placeholders.gd`), documented in a README
- DESIGN.md, `data/levels/README.md`, `assets/sprites/ui/README.md` updates
- GUT tests for every new script and the level data, in the same PR as the code

**Out of scope:**
- Running total of the fox's plate (deliberately never shown — the child divides)
- Remainders (every total divides evenly by the plate count)
- Fruit in bags (e.g. bags of 5); a two-step "how many plates" grouping round
- Final art: guests are tinted copies of the fox sheets; "sad" reuses `character_fall.png`
- Adaptive difficulty, audio, persisting the generated puzzle across restarts

---

## Design decisions

| Decision | Choice | Why |
|---|---|---|
| What the child does | Fills only the fox's plate, then presses Go; the basket deals the fox's amount to the others | The child commits to one share (total ÷ plates); dealing one by one would just be counting |
| Infinite basket | Like the market crate: each basket holds one ready `FruitDrag`; placing it spawns the next | Reuses the market's proven pattern |
| Basket label | Shows the fruit's total until Go; during the deal it counts down to what's left | The number the child divides; the countdown shows leftovers on a wrong answer |
| Fox plate cap | A fruit's row takes at most `min(max_pieces_per_row, total)` pieces; one more bounces back | The fox can't take more than the basket holds |
| Deal | Fox's pieces leave the basket first (label drops by that much), then each guest in turn gets `min(fox amount, left)` of each fruit, `deal_step` seconds apart, shown as small fruit icons on their plate | Too many → later plates come up short; too few → fruit left in the basket |
| Result | `correct` iff every fruit's fox amount × plates == total. Guests short of any fruit play `sad`; on correct all guests play `celebrate` | One Go; every fruit must be right |
| Guests | The mechanic spawns one `AnimatedSprite2D` per extra plate from a `guest_frames: SpriteFrames` export (animations `idle`, `celebrate`, `sad`), tinted from `guest_tints` | Guests' count changes per puzzle, so the mechanic owns them; the art is passed in by the world scene, so the mechanic stays world-agnostic |
| Fox | Stays in the world scene as `Character` (like other worlds); the world plays its reactions | Consistent with forest, sky, market |
| Reset during a deal | `reset()` bumps a round counter; after every await the deal coroutine stops if the round changed or the mechanic is no longer inside the tree (world switched mid-deal) | Same guard as `WorldBase._load_count` |
| Fruit visuals | `item_icons: Dictionary` (fruit id → Texture2D) export set in the world scene | "strawberry" is only a data key to the mechanic |
| Plates & shares | Plates 2–5 (incl. the fox) per level; share 2–10 per fruit | Up to 50 ÷ 5; 5 plates is the most that fit across the top of the screen |

## Implementation Steps

### 1. Placeholder art — `tools/make_picnic_placeholders.gd`, `assets/sprites/picnic/`, `assets/sprites/ui/icon_world_picnic.png`
Headless `SceneTree` script in the style of `make_market_placeholders.gd` (own copies of the small drawing helpers). Draws:
- `bg_picnic.png` 1800×1000: sky, meadow, a checked blanket under the play area
- `tray.png` 640×260: the fox's big plate (drawn as a `NinePatchRect`, 16 px margins)
- `guest_plate.png` 170×100: a guest's plate
- `basket.png` 120×80: wicker basket (front), blank face
- `icon_strawberry.png`, `icon_apple.png` (green), `icon_banana.png`, each 64×64
- `ui/icon_world_picnic.png` 128×128
Run it, then `Godot --headless --import`. Write `assets/sprites/picnic/README.md` (every file is a placeholder; sizes; guests are tinted fox sheets; Go/retry reuse forest icons). Add the icon row to `assets/sprites/ui/README.md`.

### 2. `FruitDrag` — `scripts/mechanics/fruit_drag.gd`, `scenes/mechanics/fruit_drag.tscn`
- `class_name FruitDrag extends DragPiece`; `const TOUCH_PADDING := Vector2(8, 8)`; `var item: String`.
- `configure(item_id: String, icon: Texture2D)` sets `item` and both textures; `get_width() -> float` returns `$Body.size.x`; overrides `_touch_padding()`.
- Scene: `Shadow` TextureRect (64×64 at (−28, −26), modulate (0, 0, 0, 0.3), hidden), `Body` TextureRect (64×64 at (−32, −32), expand ignore size, keep aspect centred). Both `mouse_filter = IGNORE`.

### 3. `SharingPuzzleGenerator` — `scripts/mechanics/sharing_puzzle_generator.gd`
`static func generate(params: Dictionary, rng: RandomNumberGenerator) -> Dictionary` returns `{"plates": int, "orders": Array[Dictionary]}`; plates from `params["plates"]` {min,max} once; per `params["items"]` entry `{"item", "share", "total": plates × share}` with share from the entry's `share` {min,max}.

### 4. `SharingMechanic` — `scripts/mechanics/sharing_mechanic.gd`, `scenes/mechanics/sharing_mechanic.tscn`
Placed at world (640, 360), so local (0, 0) is the screen centre.

Exports (defaults): `item_icons: Dictionary`, `go_texture`, `basket_texture`, `guest_plate_texture`, `guest_frames: SpriteFrames`, `guest_tints: Array[Color]`, `guest_scale = 2.0`, `plate_rect = Rect2(-390, -30, 640, 260)`, `row_y = [20, 100, 180]`, `row_left = -370`, `row_right = 230`, `basket_x = 350`, `piece_gap = 8`, `max_pieces_per_row = 12`, `guest_left = -300`, `guest_right = 540`, `guest_y = -210`, `guest_plate_y = -100`, `mini_icon_size = 28`, `deal_step = 0.45`.

Scene children: `Tray` (NinePatchRect, `mouse_filter` ignore), `Guests` (Node2D), `Baskets` (Node2D), `PlacedFruit`, `Leaving`, `ReadyFruit` (Node2D each), `GoButton` (TextureButton, 110×110 at local (440, 230)).

Public API (all `##` documented):
- `setup(plates: int, orders: Array[Dictionary])` — orders need `item`, `total`; stores both, calls `reset()`.
- `reset()` — bumps the round, frees placed/ready/leaving fruit, rebuilds baskets (Sprite2D + a font-44 Label showing the total to the right of the basket), rebuilds `plates − 1` guests (Node2D with `Animal` AnimatedSprite2D playing `idle`, tinted `guest_tints[i % size]`, a `Plate` Sprite2D and a `Fruit` Node2D), spawns one ready piece per basket.
- `confirm()` — disables input and starts the deal coroutine (see design table). After the last guest it waits `deal_step`, sets guest reactions, then emits `correct` or `incorrect`. Does nothing while a deal is running.
- `set_interactive(enabled: bool)` — Go button + every ready/placed piece.
- `is_dealing() -> bool`, `get_orders()`, `get_plate_count()`, `get_placed_count(item)`, `get_placed_pieces(item) -> Array[FruitDrag]`, `get_ready_piece(item) -> FruitDrag`, `get_basket_count(item) -> int` (number on the basket label), `get_dealt_count(guest: int, item) -> int`, `get_guest(guest: int) -> AnimatedSprite2D`.

Input: dropping a ready piece inside `plate_rect` or tapping it places it (row cap: `min(max_pieces_per_row, total)`); otherwise it bounces back. Tapping a placed piece sends it back to its basket and frees it. Row layout like `MarketMechanic._relayout_row` (overlap when crowded). Guest plate minis: Sprite2D per fruit, one row per fruit at plate-relative y −28/0/28, step `min(mini_icon_size + 2, (150 − mini_icon_size) / (n − 1))`.

### 5. World — `scripts/worlds/picnic.gd`, `scenes/worlds/picnic/picnic.tscn`
- Scene: Background, Camera2D (640, 360), `Character` (fox AnimatedSprite2D at (150, 470), scale 2.5; `FoxFrames` with `idle`, `celebrate`, `sad` (fall sheet, no loop)), `SharingMechanic` at (640, 360) with `item_icons`, `go_texture`, `guest_frames` = the same `FoxFrames`, `guest_tints` (four soft colours), `CelebrationParticles` (same confetti as market), `RetryPrompt/RetryIcon`, `LevelHud`.
- `_world_id()` → `"picnic"`. `_setup_level()`: restore stage, `var puzzle := SharingPuzzleGenerator.generate(level, _rng)`, `_mechanic.setup(puzzle["plates"], puzzle["orders"])`, `set_interactive(true)`.
- `_on_correct`: fox `celebrate`, confetti, wait `celebrate_duration`, `_advance()` (guarded by `_load_count`).
- `_on_incorrect`: fox `sad`, wait `sad_duration` (export, 0.8), show retry (guarded).
- Retry: hide prompt, fox `idle`, `_mechanic.reset()`, `set_interactive(true)`.

### 6. Level data — `data/levels/world_picnic/`
20 files + `levels.json` (see Data Changes).

### 7. Registry — `scripts/autoloads/game_registry.gd`
Append `{"id": "picnic", "scene": "res://scenes/worlds/picnic/picnic.tscn", "icon": "res://assets/sprites/ui/icon_world_picnic.png"}`.

### 8. Tests — `tests/` (see Test Plan), including `test_game_registry.gd` update.

### 9. Docs — `DESIGN.md`, `data/levels/README.md`
DESIGN: World 4: The Picnic section, `SharingMechanic` row (Division), future worlds become 5 and 6. Levels README: picnic schema and field table.

### 10. Verify
Full GUT suite, gdlint on new files, a 1280×720 screenshot of levels 1, 10 and 20 (plus an iPhone-ish 19.5:9 aspect) to check layout, then a web export.

## Data Changes

`data/levels/world_picnic/world_picnic_NN.json`:

```json
{
  "id": "world_picnic_11",
  "world": "picnic",
  "mechanic": "sharing",
  "plates": { "min": 2, "max": 2 },
  "items": [
    { "item": "strawberry", "share": { "min": 2, "max": 3 } },
    { "item": "apple", "share": { "min": 2, "max": 3 } },
    { "item": "banana", "share": { "min": 2, "max": 3 } }
  ],
  "narrative_key": "picnic_11",
  "skill_tags": ["division", "fair-sharing"]
}
```

| Field | Type | Description |
|---|---|---|
| `plates.min/max` | int | Inclusive range for the number of plates, the fox's included (2–5) |
| `items[].item` | String | Fruit id; must have an icon in the world scene |
| `items[].share.min/max` | int | Inclusive range for how many of that fruit each plate should get (2–10) |

Progression (plates / share; every fruit in a level uses the same share range):

| Levels | Fruit | Plates and share per level |
|---|---|---|
| 1–5 | strawberry | 2/2–3, 2–3/2–4, 3/2–5, 3–4/3–6, 4–5/4–8 |
| 6–10 | + apple | same as 1–5 |
| 11–20 | + banana | 2/2–3, 2–3/2–4, 3/2–4, 3/3–5, 3–4/3–6, 3–4/4–7, 4/4–8, 4–5/5–8, 4–5/6–9, 5/7–10 |

## Definition of Done
- [ ] `SharingMechanic` emits `correct` only after the deal, when every fruit's fox amount × plates equals its total
- [ ] Too many: the last guests' plates are short and those guests play `sad`; too few: the basket label shows what's left; both emit `incorrect`
- [ ] No label shows the fox's placed amount; basket labels show totals until Go
- [ ] Tap and drag both place fruit; tapping placed fruit removes it
- [ ] Picnic is the fourth world in the picker; levels 1–20 load and are solvable in order
- [ ] Levels 1–5 strawberry, 6–10 + apple, 11–20 + banana; plates 2–5; share 2–10
- [ ] Every public method, export and signal has a `##` doc comment
- [ ] Full GUT suite passes; gdlint clean on new files
- [ ] Layout checked on screenshots of levels 1, 10 and 20; web export builds
- [ ] Tests and docs are in the same PR as the code; PR is not merged without the user's go-ahead
